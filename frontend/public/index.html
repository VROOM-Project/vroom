      Cost per kilometre
        What a kilometre of that truck really costs the company: fuel, tyres, wear, everything that scales with the road. Trucks of one type are identical, so this is per type. Only the differences between the types decide which truck drives.
        Chico
          What attaching a chico does to that truck's cost per kilometre: 1.25 means a quarter dearer with the trailer on. At 1 the solver takes a chico whenever it saves kilometres. Hitching time is time, and time is not priced.
          What the solver is told
          Limits per truck
          Hard caps, not costs: a route breaking one of them is not a plan at all, so operations get left for tomorrow rather than made expensive. 0 means no limit. A task is one shipment step, not one operation: an exchange is four (load the empty and drop the full at the company, leave the empty and take the full at the client).
          Search
          Exploration is how hard the solver looks: 5 is the best plan and the slowest, 0 the quickest. Following the roads asks for the driven route (vroom's -g) so the map draws real streets and kilometres are reported; without it the map draws straight lines. A per km cost or a distance limit needs it and turns it on by itself.
          How the solver ranks plans
          1. Priority — the total priority of the operations done.
          2. Operations done — the most, whatever they cost.
          3. Cost — the kilometres, priced per truck above.
          4. Trucks used, then driving time, then distance.
          Each line only speaks when the ones above it are tied, so cost never drops an operation to save money. Nothing prices the drivers' time: they are paid by the month whether a truck goes out or not, so the plan cannot spend it and does not try to save it. Their day is a limit instead — the working hours in Config, and the caps below.
          Fleet
            Trucks of each type available today, and chicos: trailers that make a truck carry three allowed loads at once. The solver decides which trucks take a chico, never more than the trucks of that type. Materials travel in a full container of the chosen size. Loading rules per type follow docs/waste_transport_problem.md.
            Working day
            Lunch is a fixed break from start to end for every truck. Set both to the same time for no lunch.
